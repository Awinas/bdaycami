# A Birthday Garden for Ishami ♡

A cute, responsive, multi-page birthday website celebrating tulips 🌷, cats 🐈, and books 📚.

## Pages
- `index.html`: landing page and countdown to November 1
- `letter.html`: birthday letter with a hidden message
- `garden.html`: interactive tulip picking garden
- `cats.html`: click-to-interact cat café
- `library.html`: book nook and reading progress tracker
- `wishes.html`: random birthday wish jar and mini quiz

## Publish with GitHub Pages
1. Create a **public** repository on GitHub, for example `birthday-for-ishami`.
2. Upload every file in this folder to the repository root. Keep the folder structure flat.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the deployment check to finish. The URL will look like `https://YOUR-USERNAME.github.io/birthday-for-ishami/`.

## Personalise it
- Search for `Ishami` in the HTML files to change the displayed name.
- The countdown is set to November 1 in the visitor's local timezone. Edit `script.js` if you want a different date.
- The optional tune is generated by the browser using Web Audio. It starts only after the visitor taps the tune button.
- Google Fonts are used when internet access is available; system fallbacks are included.

No build tools, frameworks, API keys, or backend are needed. This is a static GitHub Pages site.
